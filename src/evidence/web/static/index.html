Pack

A pack is a set of generated loan cases whose right answer was computed before any model ran. Choose one to see its cases, mark a briefing by hand, or run the assistant under test over all of it.

Case

What the assistant sees, and — sealed from it — what a briefing must state. The marking key was computed from the scorecard that decided the case; decoys are fields with no weight in that decision.

Gate

Type or paste a briefing for the selected case and mark it. Nothing here calls a model: each check is a comparison against the sealed key. Try a briefing that is fluent and true but leaves out the policy limit, or one with a made-up ratio.

Run

Put every case in the pack to the assistant under test, N times, and mark every briefing. Transcripts are written as they arrive, so a stopped run resumes. The judge grades readability only and is reported, not gated.

Verify

Re-hash every file in the run against checksums.sha256, then re-run every deterministic check from the transcripts and compare with the recorded results. The tamper demo copies the run, changes one digit, and verifies the copy — the original is untouched.
