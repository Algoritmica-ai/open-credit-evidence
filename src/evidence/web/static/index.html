Pack

A pack is a set of generated loan cases whose right answer was computed before any model ran. Choose one, build a new one from a Synthetic Data Designer spec, or upload a pack built elsewhere.

Where the cases come from · Synthetic Data Designer

Every case is generated by Synthetic Data Designer (SDD) from a YAML recipe. The recipe gives each applicant a hidden repayment capacity and writes out only noisy readings of it, plus fields that have no path to the outcome. A scorecard then decides each application, so the right answer — and the marking key — exist before any model runs.

Open SDD ↗ SDD source ↗ Download this recipe

To change the cases: download the recipe, open SDD and load it in its spec step, edit it and export the YAML, then use Build a pack from a spec below.

What this pack tests against the EU AI Act

Per article: what the Act requires, the level the pack claims — evidences, contributes, or not covered — and for each check what it tests and why that is evidence for the article. Planned checks are named as planned, never counted.

Regulation corpus for the judge

The passages the judge is handed and must cite. Built from the source texts under regulations/<CC>/ into a versioned, hashed index — a standalone step, run when the texts change, never during an evaluation. Every judge result records the passages it saw and the corpus hash.

Verify

Re-hash every file in the run against checksums.sha256, then re-run every deterministic check from the transcripts and compare with the recorded results. The tamper demo copies the run, changes one digit, and verifies the copy — the original is untouched.

Compare

Did a change help? Pick the run before the change and the run after it — same pack, one thing changed (the model, its instructions, what it is handed). Each case is compared with itself, so the answer is per check: how many cases the change helped, how many it hurt, and a 95% interval, so run-to-run noise is not mistaken for progress.
